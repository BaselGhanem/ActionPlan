تهيئة النظام على Firebase Spark

نفّذ الخطوات مرة واحدة في مشروع dadactionplan. استخدم حسابك في Firebase Console.

  1. في Authentication فعّل طريقة تسجيل الدخول Email/Password وأضف baselghanem.github.io ضمن Authorized domains.
  2. في Firestore افتح Rules، استبدل القواعد بالمحتوى أدناه واضغط Publish.

  3. في Authentication ← Users ← Add user أنشئ البريد admin@users.dadactionplan.app وكلمة مرور تختارها، ثم انسخ UID للحساب.
  4. في Firestore ← Data أنشئ collection اسمها setup ومستندا بالمعرّف bootstrap. أضف الحقل adminUid من نوع string والصق UID السابق كما هو.
  5. افتح صفحة الدخول، واكتب اسم المستخدم admin وكلمة مرورك. سيُهيّئ النظام ملف المسؤول. أضف الفرق والميزانيات والقوائم والحسابات من الإدارة.
